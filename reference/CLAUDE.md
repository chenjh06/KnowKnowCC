**快速参考** - 问题解决者的快速通道

目标：让用户在遇到问题时能够快速找到解决方案。

## 使用技巧

### 技巧 1: 收藏常用命令

创建个人速查表：

```markdown
# 我最常用的命令

## 文件操作
@file.txt          # 引用文件
读取 file.txt       # 读取内容

## 命令执行
!npm test          # 运行测试
!git status        # Git 状态

## 快捷键
Esc                # 撤销
Shift+Tab          # Plan 模式
Ctrl+R             # 历史搜索
```

### 技巧 2: 打印速查表

```
1. 打印 shortcuts.md
2. 放在桌面旁边
3. 随时查看
4. 形成肌肉记忆
```

### 技巧 3: 问题诊断流程

```
遇到问题
    ↓
troubleshooting.md
    ↓
按照诊断树
    ↓
定位问题
    ↓
应用解决方案
    ↓
已解决？
    ├─ 是 → 完成
    └─ 否 → 查看详细文档/提交 Issue
```

## 常见问题 (FAQ)

### Q1: 如何快速找到需要的命令？

**A**:
1. 查看 [commands.md](commands.md) 命令速查表
2. 按功能分类查找
3. 查看使用示例
4. 直接复制使用

### Q2: 最常用的快捷键有哪些？

**A**: 必记的 5 个快捷键：

| 快捷键 | 功能 | 频率 |
|--------|------|------|
| `@` | 引用文件/目录 | ⭐⭐⭐⭐⭐ |
| `!` | 运行命令 | ⭐⭐⭐⭐⭐ |
| `Esc` | 撤销操作 | ⭐⭐⭐⭐⭐ |
| `Shift+Tab` | Plan 模式 | ⭐⭐⭐⭐ |
| `Ctrl+R` | 历史搜索 | ⭐⭐⭐⭐ |

详见：[shortcuts.md](shortcuts.md)

### Q3: 遇到错误怎么快速定位？

**A**:
1. 查看 [troubleshooting.md](troubleshooting.md) 问题诊断树
2. 按照流程图排查
3. 找到对应的解决方案
4. 应用修复

### Q4: 如何知道是否有新版本？

**A**:
1. 定期查看 [changelog.md](changelog.md)
2. 了解新功能和变更
3. 评估是否需要升级
4. 查看升级指南

### Q5: 这些速查表需要记忆吗？

**A**:
- **不需要全部记忆**
- **分阶段掌握**：
  - 第 1 周：熟悉 commands.md，掌握 10 个基础命令
  - 第 2 周：学习 shortcuts.md，掌握 5 个快捷键
  - 第 3 周：了解 troubleshooting.md，掌握诊断流程
- **持续使用**：定期查阅 changelog.md

### Q6: 速查表和详细文档有什么区别？

**A**:

| 维度 | 速查表 | 详细文档 |
|------|--------|---------|
| 目的 | 快速查找 | 深度学习 |
| 内容 | 命令/快捷键 | 概念/原理/案例 |
| 使用 | 即用即查 | 系统学习 |

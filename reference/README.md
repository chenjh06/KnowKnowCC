## 💡 使用技巧

### 技巧 1: 收藏常用命令

```markdown
创建个人速查表：

# 我最常用的命令

## 文件操作
@file.txt          # 引用文件
读取 file.txt       # 读取内容

## 命令执行
!npm test          # 运行测试
!git status        # Git 状态

## 快捷键
Esc                # 撤销
Shift+Tab          # Plan 模式
Ctrl+R             # 历史搜索
```

### 技巧 2: 打印速查表

```
1. 打印 shortcuts.md
2. 放在桌面旁边
3. 随时查看
4. 形成肌肉记忆
```

### 技巧 3: 问题诊断流程

```
遇到问题
    ↓
troubleshooting.md
    ↓
按照诊断树
    ↓
定位问题
    ↓
应用解决方案
    ↓
已解决？
    ├─ 是 → 完成
    └─ 否 → 查看详细文档/提交 Issue
```

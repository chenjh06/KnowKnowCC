### ⚠️ 重要提示：Shift+Tab Plan 模式 Bug

**Windows 用户注意**：

Claude Code 2.1.3 版本在 Windows 上存在已知 Bug：
- **问题**：`Shift+Tab` 可能无法进入 Plan 模式
- **症状**：只能切换到 Auto-accept 模式
- **影响**：Windows 用户无法使用快捷键进入 Plan 模式

**解决方案**：

1. **使用 /plan 命令**（推荐）
   ```
   /plan
   ```

2. **明确要求规划**
   ```
   请先用 Plan 模式规划这个任务
   ```

3. **等待版本更新**
   - Bug 详情：[GitHub Issue #17344](https://github.com/anthropics/claude-code/issues/17344)
   - 影响版本：Claude Code 2.1.3 (Windows)

**替代快捷键**：
- `Alt+M` - 在某些配置下可用
- `/plan` - 命令方式（100% 可靠）

## 效率提升技巧

### 技巧 1：使用 Esc 后悔药

**优势**：
- 做错立即撤销
- 可多次使用
- 避免重复输入

**最佳实践**：
```
操作 → 观察 → 不满意 → Esc → 重新操作
```

### 技巧 2：善用 Ctrl+R

**优势**：
- 搜索历史提示词
- 复用之前的长文本
- 提高输入效率

**最佳实践**：
```
Ctrl+R → 输入关键词 → 找到历史 → 回车执行
```

### 技巧 3：Plan 模式规划

**优势**：
- Shift+Tab 进入
- 规划后再执行
- 避免盲目操作

**最佳实践**：
```
描述任务 → Shift+Tab → 审查计划 → 确认执行
```

### 技巧 4：自定义快捷键

**优势**：
- 绑定常用功能
- 减少操作步骤
- 个性化工作流
- 提升专业效率

#### 配置方法

Claude Code 支持自定义快捷键（**预览功能**）

**创建配置文件**：
```
/keybindings
```

**配置文件位置**：
```
~/.claude/keybindings.json
```

#### 配置示例

**基础配置**：
```json
[
  {
    "context": "Chat",
    "bindings": {
      "ctrl+e": "chat:externalEditor",
      "ctrl+u": null
    }
  }
]
```

**说明**：
- `context`: 应用上下文
  - `Chat` - 主聊天输入区
  - `Global` - 全局应用
  - `Autocomplete` - 自动完成菜单
  - `HistorySearch` - 历史搜索模式
- `bindings`: 按键绑定映射
  - `"ctrl+e": "chat:externalEditor"` - 绑定快捷键
  - `"ctrl+u": null` - 取消绑定（禁用默认快捷键）

#### 常用上下文和动作

**全局动作** (`Global`)：
| 动作 | 说明 |
|------|------|
| `app:interrupt` | 取消当前操作（默认 Ctrl+C） |
| `app:exit` | 退出 Claude Code（默认 Ctrl+D） |
| `app:toggleTodos` | 切换待办列表（默认 Ctrl+T） |
| `app:toggleTranscript` | 切换对话记录 |

**聊天动作** (`Chat`)：
| 动作 | 说明 |
|------|------|
| `chat:submit` | 发送消息 |
| `chat:externalEditor` | 打开外部编辑器 |
| `chat:insertNewline` | 插入新行（不发送） |

#### 实用配置示例

**示例 1：增强编辑体验**
```json
[
  {
    "context": "Chat",
    "bindings": {
```

#### 按键语法

- `ctrl+e` - 单个修饰键 + 字母
- `ctrl+shift+e` - 多个修饰键
- `ctrl+e f` - 按键序列（chord）

## 常见问题

### Q1: Esc 撤销后如何恢复？

**A**: 使用 `/redo` 命令或重新输入

**示例**：
```
操作后按 Esc → 已撤销
输入 "redo" → 恢复操作
```

### Q2: 快捷键不工作怎么办？

**A**: 检查以下几点：
1. **键盘布局**：确保使用正确的键盘布局
2. **终端配置**：检查终端是否捕获了快捷键
3. **系统设置**：
   - Windows: 检查 Windows Terminal 设置
   - macOS: 检查系统偏好设置 → 键盘
   - Linux: 检查终端快捷键设置
4. **冲突检测**：是否有其他程序占用了快捷键

### Q3: 如何查看所有快捷键？

**A**: 有三种方式：
1. **本文档**：完整快捷键列表
2. **Claude Code 文档**：官方快捷键说明
3. **`/help` 命令**：内置帮助

### Q4: macOS 和 Windows 快捷键有什么区别？

**A**: 主要区别：
- `Ctrl` (Windows) = `⌘ Command` (macOS)
- `Alt` (Windows) = `⌥ Option` (macOS)
- `End`/`Home` (Windows) = `⌘+→/←` (macOS)
- `Page Up/Down` (Windows) = `Fn+↑/↓` (macOS)

### Q5: 如何记忆快捷键？

**A**: 分阶段掌握：

**第 1 周（核心）**：
- `Esc` - 撤销
- `@` 和 `!` - 文件引用和命令执行
- `Shift+Tab` - Plan 模式

**第 2 周（导航）**：
- `Ctrl+R` - 历史搜索
- `↑/↓` - 历史浏览
- `Ctrl+A/C/V` - 编辑基础

**第 3 周（进阶）**：
- 自定义快捷键
- 组合使用
- 形成习惯

### Q6: Windows Terminal 中如何设置快捷键？

**A**: 通过设置 UI：
1. 打开 Windows Terminal
2. 按 `Ctrl+,` 打开设置
3. 选择"操作" → "添加新操作"
4. 配置快捷键和对应命令

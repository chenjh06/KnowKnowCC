#### 🔴 问题 #1: WinGet包名错误

**文档**: `guide/01-quickstart.md`
**位置**: 第28-36行
**严重程度**: 🔴 严重
**发现日期**: 2026-01-26
**状态**: ⏳ 待修正

**问题描述**:
Windows WinGet安装命令中的包名错误，导致Windows用户无法安装Claude Code。

**原内容**:
```powershell
winget install Claude.ClaudeCode
```

**正确内容**:
```powershell
winget install Anthropic.ClaudeCode
```

**影响**:
- 所有使用WinGet安装的Windows用户
- 安装失败率：100%
- 用户流失风险：高

**验证方法**:
- 官方文档对照: https://code.claude.com/docs/zh-CN/setup
- 官方命令: `winget install Anthropic.ClaudeCode`

**修正方案**:
1. 立即更新文档中的包名
2. 添加官方推荐的PowerShell安装脚本作为备选
3. 更新CHANGELOG记录修正

**优先级**: **P0 - 立即修正**

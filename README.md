## 什么是 knowknowcc？

**knowknowcc（看懂 Claude Code）** 是一个精心设计的知识体系，帮助你从零开始掌握 Claude Code。

### 设计理念

- 不是技巧的堆砌和罗列，也不是覆盖所有功能的百科全书
- 而是精选 **20% 最核心的内容**，解决 **80% 的使用场景**
- 每个概念都讲透原理、实践、案例

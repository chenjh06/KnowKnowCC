```markdown
**解决方案**：
- ✅ 使用 `/plan` 命令直接进入 Plan 模式

- ✅ 或等待版本更新修复

**Bug 详情**：
- GitHub Issue: [#17344](https://github.com/anthropics/claude-code/issues/17344)
- 影响版本：Claude Code 2.1.3 (Windows)
- 状态：已知问题，等待修复

**替代命令**：
```
/plan                    # 直接进入 Plan 模式
请规划这个任务            # 明确要求规划
```
```

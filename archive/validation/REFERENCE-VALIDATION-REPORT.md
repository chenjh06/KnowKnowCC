```markdown
## 自定义快捷键

Claude Code 支持自定义快捷键（预览功能）

### 配置文件

**位置**: `~/.claude/keybindings.json`

**创建配置**:
```bash
# 运行命令创建配置文件
/keybindings
```

### 配置示例

```json
[
  {
    "context": "Chat",
    "bindings": {
      "ctrl+e": "chat:externalEditor",
      "ctrl+u": null
    }
  }
]
```

**说明**:
- `context`: 应用上下文（Chat, Global, Autocomplete 等）
- `bindings`: 按键绑定映射
- `null`: 取消绑定

### 常用上下文

| 上下文 | 说明 |
|--------|------|
| `Global` | 全局应用 |
| `Chat` | 主聊天输入区 |
| `Autocomplete` | 自动完成菜单 |
| `HistorySearch` | 历史搜索模式 (Ctrl+R) |

**注意**: 此功能目前处于预览阶段，可能不适用于所有用户
```

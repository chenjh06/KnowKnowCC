## 快捷键概述

### 为什么快捷键重要？

```
使用快捷键：
- ⚡ 速度提升：比菜单操作快 5-10倍
- ✅ 保持心流：不中断思考流程
- 🎯 专业形象：展现你的专业水平

不使用快捷键：
- 🐌 频繁使用鼠标
- 🐌 中断编程节奏
- 🐌 降低工作效率
```

## 平台差异

### Windows 快捷键

| 功能 | 默认 | 可自定义 |
|------|------|---------|
| 中断 | `Ctrl+C` | 可配置 |
| 退出 | `Ctrl+D` | 可配置 |
| 清屏 | `Ctrl+L` | 可配置 |

#### 终端快捷键

**Windows Terminal 推荐**：

```json
// settings.json
{
  "keybindings": {
    "Ctrl+Shift+C": "copy",
    "Ctrl+Shift+V": "paste",
    "Ctrl+Shift+N": "new-tab",
    "Ctrl+Shift+W": "close-tab"
  }
}
```

| 功能 | 默认 | 说明 |
|------|------|------|

| 退出 | `Cmd+D` | 与 Windows 不同 |
| 清屏 | `Cmd+K` | 与 Windows 不同 |
| 历史 | `Cmd+↑/↓` | 与 Windows 不同 |

### Linux 快捷键

| 功能 | 默认 | 说明 |

| 中断 | `Ctrl+C` | 与 Windows 相同 |
| 退出 | `Ctrl+D` | 与 Windows 相同 |
| 清屏 | `Ctrl+L` | 与 Windows 相同 |
| 历史 | `Ctrl+R` | 与 Windows 相同 |

## 自定义快捷键

### 创建别名（最实用）

#### Windows PowerShell 别名

```powershell
# 创建别名
function cc { claude $args }
function ccd { cd $args }

# 查看别名
Get-Alias | Where-Object {$_.Name -like "c*"}
```

#### Bash 别名

```bash
# 添加到 .bashrc 或 .zshrc
alias cc='claude'
alias ccd='cd'
alias cc-log='claude --session log'
```

### 创建快捷键脚本

#### 脚本示例

```powershell
# scripts/quick-commands.ps1

# 快捷键：Alt+C
function Start-Claude {
    $cwd = Get-Location
    cd D:\Projects\$env:PROJECT
    claude
}

# 设置快捷键（使用 Windows Terminal）
# 在 Settings.json 中：
{
  "global": {
    "键位": "alt+c",
    "command": "powershell -File D:\\Scripts\\quick-commands.ps1; Start-Claude"
  }
}
```

## 常见问题

### Q1: 快捷键不工作怎么办？

**A**: 检查以下内容：

```markdown
1. 检查是否在正确模式
   - 确保在对话中（不是编辑器中）

2. 检查终端配置
   - Windows Terminal → 设置 → 快捷键
   - 检查是否有冲突

3. 检查是否有插件冲突
   - 禁用可能冲突的插件

4. 使用完整路径
   - 某些终端需要完整路径
```

---

### Q2: 如何查看所有快捷键？

**A**:

```
👤 你：列出所有可用的快捷键

🤖 Claude：
以下是可用的快捷键：
... [列出所有快捷键]
```

---

### Q3: 可以自定义 Esc 键吗？

**A**: 不能，Esc 键是固定的撤销功能。

---

### Q4: 可以禁用某个快捷键吗？

**A**: 某些快捷键可以禁用：

```json
// settings.json
{
  "disableShortcut": {
    "esc": false  // 不能禁用
    "shift-tab": false  // 不能禁用
    "ctrl+r": false  // 可以禁用历史搜索
  }
}
```

---

### Q5: Ctrl+R 历史搜索不工作？

**A**: 可能的原因和解决方案：

```markdown
1. 检查是否有历史记录
👤 你：/stats
→ 查看"连续使用天数"确认

2. 检查是否在对话中
   - Ctrl+R 在对话中搜索提示词
   - 在命令行中搜索命令

3. 检查历史记录
   - Bash：↑/↓ 浏览命令历史
   - 对话：Ctrl+R 搜索提示词历史

4. 检查配置
   - 某些环境可能禁用了历史
```
